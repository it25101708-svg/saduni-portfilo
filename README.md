# Saduni Ranasinghe - Educator Portfolio

An interactive, modern portfolio and management dashboard web application built with **React**, **Vite**, **TypeScript**, and **Tailwind CSS**.

---

## 🚀 Quick Start

### 1. Run Development Server
You can either:
- **Double click** the included `run.bat` file in this folder.
- Or open your terminal and run:
  ```bash
  npm run dev
  ```

The site will automatically launch at **[http://localhost:5173](http://localhost:5173)**.

---

## 🛠️ Available Scripts

- **`npm run dev`** — Starts the local Vite development server with Hot Module Replacement (HMR).
- **`npm run build`** — Compiles TypeScript and builds production-ready static assets in `/dist`.
- **`npm run preview`** — Locally previews the production build.

---

## 🔐 Admin Studio Access & Separate Links
You can now access the Admin Studio through multiple direct ways:

1. **Direct URL Links**:
   - `http://localhost:5173/#admin` *(direct hash link)*
   - `http://localhost:5173/admin` *(direct route)*
2. **Top Navigation Bar**: Click the **"Admin Portal"** button with the lock icon located in the header.
3. **Mobile Menu**: Open the hamburger menu on mobile devices and select **"Admin Studio Portal"**.
4. **Footer**: Click the **"Admin Studio Portal (Direct Link)"** at the bottom of the page.
5. **Keyboard Shortcut**: Press `Ctrl + Shift + A` anywhere on the site.

- **Default Admin PIN**: `1234`
- You can change the Security PIN inside **Admin Studio → Settings**.
- Click **"Exit to Public Website"** at any time to return to the public portfolio.

---

## ✨ Features
- **Hero & Profile Showcase**: Customizable teacher bios, role tags, statistics badges, and profile portrait.
- **Classes, Workshops & Mentorships**: Filterable course catalog with schedules, descriptions, and gallery images.
- **Student & Parent Reviews**: Verified reviews section with rating stars and admin approval workflow.
- **Interactive Contact & WhatsApp**: Direct WhatsApp inquiry generation and built-in inquiry message inbox.
- **Full Admin Control**: Update profile details, add/edit/delete classes, approve reviews, view inquiries, and backup/restore data.
